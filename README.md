# cu1-obisidian

个人 Obsidian 知识库，用于沉淀技术笔记、项目方案与日常记录。

## 项目结构

```
.
├── note/         # 技术笔记
├── project/      # 项目相关文档
├── jinchanchan/  # 游戏相关素材
└── sop/          # 标准操作流程（待补充）
```

### note/ — 技术笔记

- **ES/**：Elasticsearch 相关（待补充）
- **Java/**
  - `jvm/`：JVM 相关，含 `G1`、`ZGC`、`GC 通述`
  - `新特性/`：Java 新特性，如 `Java Record 关键字`
  - `线程池/`：线程池源码讨论
- **redis/**：Redis 最佳实践、大 Value 拆分与多 key 合并方案、高可用部署，以及思维导图
- **方案设计/**：方案类文档，如《二级缓存解决热 key 问题》
- **碎碎念/**：非技术内容
  - `music/`：专辑记录
  - `travelogue/`：游记
  - `日常开发注意点.md`、`结论正确性思考.md`
- **面试问题记录/**：常见问题 Q&A、反问清单

### project/ — 项目文档

- **hot-deployment/**：热部署项目，按 `lean` / `plan` / `spec` / `task` 四个阶段组织
- **raptor/**：Raptor 项目，目前仅含 `spec`

### jinchanchan/

- `s17/`：游戏相关图片素材

### sop/

标准操作流程目录，当前为空。
