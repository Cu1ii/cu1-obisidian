# 电影台词搜索引擎（中文版 quodb）

## 一句话定位

> 你记得一句台词，它告诉你出自哪部电影哪一秒。

中文影迷专属的台词搜索引擎，对标海外 [quodb.com](https://quodb.com)，中文场景空白。

## 核心场景

- 「再见旺角卡门」搜出处 → 跳到那一秒截图 + 上下文
- 找某主题台词（爱情/孤独/再见）→ 跨片混剪式呈现
- 一键生成台词海报卡片，朋友圈/即刻/微博分享
- 影迷收藏台词夹，长期沉淀

## 技术栈契合

| 组件 | 角色 |
|---|---|
| ES | 千万条字幕全文 + 时间戳 + 影片元数据（唯一核心） |
| Redis | 热搜词、防爬限流、热门台词榜 |
| MQ | 字幕入库管线、海报图异步生成 |
| MySQL | 影片元数据、用户、收藏 |

## 数据来源（合规）

- 公开字幕站（SubHD、A 站、subhd）字幕文件
- 用户上传补全
- TMDB / 豆瓣 公开 API 取影片元数据
- **不爬视频本体，只索引字幕文本（合理使用范畴）**

## 核心能力

### 搜索引擎本体

- 中文分词 + 拼音/错字容错 + 模糊匹配
- 上下文展示（前后 3 句）
- 时间戳精确到秒
- 多面过滤：年代/导演/演员/语言/类型

### 影迷工具

- 台词收藏夹 + 标签
- 主题台词集（用户共建：「关于离别的 30 句台词」）
- 台词海报生成器（背景图 + 字体 + 引文格式）
- 个人台词墙（公开主页 → SEO 入口）

### 自传播引擎

- 每张分享海报带产品水印
- 单条「这句话原来出自……」转发力极强
- 微博 / 豆瓣 / 即刻 是天然渠道

## 后端架构

```
[字幕源/用户上传] → [MQ 解析管线]
                       │
                ┌──────┼──────┐
                ↓      ↓      ↓
            字幕解析 时间戳对齐 元数据匹配
                ↓
            [ES 索引]（字幕条 + 影片）
                ↓
            [Redis] 热搜 / 限流
                ↓
            [MySQL] 用户 / 收藏 / 海报记录
```

## 竞争力

### 一阶（产品力）

1. **中文分词 + 容错搜索**：竞品（少数中文字幕站）只能精确匹配
2. **时间戳跳转**：搜到台词直接定位影片秒数
3. **海报生成**：单条分享 = 产品广告
4. **主题台词集**：UGC 沉淀，长期资产

### 二阶（数据 + 网络）

5. **字幕库规模**：越大越好，竞品做不全
6. **公开台词墙 SEO**：长尾流量入口
7. **影迷社区**：评论/收藏/关注

### 三阶（技术）

8. **中文模糊匹配**：同音字/错字/口音都能搜到
9. **ES 千万条字幕的查询性能**：是真后端壁垒

## 风险

- 字幕版权灰色：只展示片段、注明来源、可申诉下架
- 视频画面截图：合理使用 + 低分辨率 + 不可下载原画
- 大型片方投诉应对：DMCA 风格下架机制

## MVP（2-3 周）

**做**：
- 字幕入库（豆瓣 Top 250 + 国产经典 1000 部起步）
- ES 搜索 + 中文容错
- 影片详情页 + 台词列表
- 台词海报生成（基础版）

**砍**：
- 用户系统（先纯搜索引擎，跑通搜索体验再加）
- 收藏 / 主题集
- 视频截图（先纯文本）

## 自传播路径

1. 自己造 100 张爆款台词海报先发微博/小红书
2. 上线后影迷自发搜索分享
3. 与字幕组 / 影评公众号合作内容
4. 豆瓣电影话题渗透
