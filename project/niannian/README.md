# 念念 / 闪念流

## 一句话定位

> 你脑子里闪过的每个念头都该被接住，AI 帮你长期看清自己。

不是日记（仪式重），不是笔记（结构重），是**闪念**——5 秒内一句话/一图/一段语音的高频输入，AI 做长期归纳。

## 使用频次

一天 5–20 次。通勤、排队、走路、睡前、想到就记。

## 技术栈契合

| 组件 | 角色 |
|---|---|
| ES | 闪念全文 + 向量检索，时间/主题/情绪多面过滤 |
| Redis | 实时输入缓冲、推送队列、时光闪回胶囊 |
| MQ | AI 分析、主题归纳、周/月报、时光闪回 异步任务流 |
| MySQL | 闪念、用户、主题关系、订阅 |

## 核心形态

### 输入（极简，5 秒内完成）

- iOS / Android widget + 灵动岛入口
- iOS 快捷指令 / Android Tasker
- 浏览器插件 `Cmd+Shift+I` 唤起
- 桌面菜单栏常驻
- 语音转写（Whisper）
- 图片直接贴

### AI 处理（用户无感）

- 自动情绪标签
- 自动主题归类
- 关键词提取
- 向量化入索引

### 反馈（钩子）

- **每周一推**：本周你在想什么（AI 主题归纳）
- **时光闪回**：一年前的今天你说……
- **金句卡片**：高质量闪念自动生成精美 OG 图，一键分享
- **思想曲线**：长期主题/情绪可视化图谱
- **关联推荐**：写新闪念时，底部「你三个月前想过类似的」

## Web 端能力

1. **时间线流**：默认主页，闪念瀑布流
2. **多面搜索**：Cmd+K 全局，关键词 + 自然语言双模式
3. **主题视图**：AI 自动聚类的主题簇
4. **思想曲线**：年/月/周维度的关注主题变化图
5. **AI 对话**：跨闪念问答（"我对工作焦虑最多是什么时候？"）
6. **金句卡片生成器**：选闪念 → 选模板 → 一键出图
7. **公开主页**（可选）：选择性公开闪念，类微博/即刻

## 亮点

### 一阶（产品力）

1. **AI 当自我对话伙伴**：不是工具是朋友
2. **时光闪回**：情感钩子，每次惊喜
3. **金句卡片自传播**：Spotify Wrapped 式分享
4. **长期资产**：用一年后不会换

### 二阶

5. **跨年数据复利**：用得越久画像越准，切换成本极高
6. **公开主页 SEO**：影响力 + 拉新
7. **AI 周/月报**：截图分享天然

### 三阶（技术）

8. **个人 ES 索引**：万级闪念向量检索
9. **超低延迟输入**：MQ 异步处理，用户感知零等待

## 差异化

| 维度 | Day One | Mem.ai | Twitter 草稿 | 念念 |
|---|---|---|---|---|
| 输入门槛 | 中（日记仪式）| 中 | 低 | **极低（5 秒）** |
| AI 归纳 | 无 | 有 | 无 | **有（核心）** |
| 时光闪回 | 弱 | 无 | 无 | **强（核心钩子）** |
| 自传播 | 无 | 无 | 有 | **金句卡片** |
| 长期画像 | 无 | 有 | 无 | **思想曲线** |

中文场景几乎无对标。

## 0 法律风险

- 全部用户自产数据
- 加密存储 + 端到端可选
- 不抓任何外部数据

## MVP（4-6 周）

**做**：
- iOS / Android widget + Web App
- 闪念输入 + 文字/语音/图片
- ES 检索 + AI 标签
- 每周主题归纳推送
- 金句卡片生成

**砍**：
- 公开主页 / 社区（二期）
- 思想曲线可视化（二期）
- 端到端加密（二期）

## 风险

- AI 调用成本（用户量大需自建小模型 or 批量推理）
- 用户能否养成「闪念」习惯（入口越狠越好）
- 隐私敏感（必须把加密、不训练做透）

## 冷启动

1. 自己每天用，发金句卡到即刻 / 小红书
2. 邀请文字工作者 / 产品经理 / 学生小范围内测
3. 主打「我用了 30 天发现自己……」内容
4. 知乎 / 即刻问答渗透：「如何记录闪念？」
