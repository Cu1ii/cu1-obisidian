# 作编曲入门（Mac 免费工具） · 课程大纲

> 这份大纲定义了完成本课题后你将掌握的所有能力。
> 学习深度：标准
> 文档数量因人而异，但掌握内容不打折扣。
> 工具前提：优先使用 Mac 上可免费获得的工具，例如 GarageBand、MuseScore Studio、LMMS、Audacity；不要求购买付费插件、声卡或 MIDI 键盘。

## 核心掌握项

完成本课题后，你将能够：

### 1. 建立作编曲的基本地图
- [x] 能够区分**作曲、编曲、制作、混音**分别解决什么问题，并判断自己当前卡在哪一层。
- [x] 能够说出一首歌从想法到 demo 的最小流程：动机 → 和弦 → 旋律 → 节奏/织体 → 结构 → 粗混导出。
- [ ] 能够用「听感功能」而不是术语堆砌来描述鼓、贝斯、和弦乐器、主旋律、铺底声部各自的作用。

### 2. 用 Mac 免费工具完成最小创作闭环
- [ ] 能够在 GarageBand 中建立项目、选择轨道、录入/绘制 MIDI、使用循环素材，并导出一个音频 demo。
- [ ] 能够用 MuseScore Studio 写出简单旋律或和弦草稿，并把谱面思路迁移到 GarageBand/LMMS。
- [ ] 能够判断 Audacity、GarageBand、LMMS、MuseScore Studio 分别适合处理哪类任务，避免一开始被工具选择拖住。

### 3. 掌握旋律、和弦与节奏的入门语法
- [ ] 能够用 4 小节动机发展出 8-16 小节旋律，而不是只靠随机试音。
- [ ] 能够使用常见大调/小调三和弦进行，为旋律配出稳定但不单调的和声。
- [ ] 能够设计基本鼓组节奏，并解释底鼓、军鼓、踩镲如何共同制造律动。

### 4. 完成一首小型编曲 demo
- [ ] 能够为同一段旋律选择合适音色，并说明音色选择如何影响情绪和空间。
- [ ] 能够安排 intro、verse、chorus、bridge/outro 等基本结构，让作品有起承转合。
- [ ] 能够做最低限度的音量平衡、声像、EQ/混响处理，使 demo 清楚可听而不过载。

## 不在本课题范围内

- 不系统学习传统四部和声、复杂爵士和声、管弦乐配器法。
- 不以专业录音棚级混音/母带为目标；只做到「能清楚表达作品想法」的 demo 级质量。
- 不要求乐器演奏能力、视唱练耳考试能力或五线谱精通；会用耳朵判断和简单记录即可。
- 不讲付费 DAW、付费音源、商业发行、版权注册、宣发运营等进阶主题。
