# 歌词写作入门 · 课程大纲

> 这份大纲定义了完成本课题后你将掌握的所有能力。
> 学习深度：标准
> 文档数量因人而异，但掌握内容不打折扣。

## 核心掌握项

完成本课题后，你将能够：

### 一、歌词的基本结构

- [x] 能够识别歌词中主歌、副歌、桥段、尾奏等段落结构
- [x] 能够分析歌词的押韵方案（尾韵、内韵、跳韵）
- [x] 能够判断断句方式如何制造停顿感与情绪节奏

### 二、主题、意象与修辞

- [x] 能够识别歌词的核心主题与情感基调
- [x] 能够分析歌词中的意象选取——具体词 vs 抽象词的比例与效果
- [x] 能够判断比喻、拟人、悖论等修辞手法在歌词中的运用效果

### 三、叙事推进与情感曲线

- [x] 能够分析歌词从头到尾的情感变化轨迹（上升、下沉、转折、爆发）
- [ ] 能够识别重复与变奏手法（换词、换视角、换语调）的作用
- [ ] 能够判断歌词结尾的收束方式——呼应、反转、留白、递进

### 四、语言风格与创作实践

- [ ] 能够判断歌词的语言风格层次（口语/书面/诗意/学术术语混用等）
- [ ] 能够分析独特词汇选择对风格辨识度的影响
- [ ] 能够用所学手法写出一段 4–8 句的歌词片段，并说明设计意图

## 不在本课题范围内

- 旋律写作、和弦编配、编曲技巧
- 押韵字典式的音韵学系统知识
- 说唱歌词的 flow 与节奏设计
- 古风/戏曲等特定体裁的形式规范
- 歌曲的商业发行、版权、市场定位
