# AI 工程技术学习路线 · 课程大纲

> 这份大纲定义了完成本课题后你将掌握的所有能力。
> 学习深度：标准
> 文档数量因人而异，但掌握内容不打折扣。

## 核心掌握项

完成本课题后，你将能够：

### 一、定位与学习地图
- [x] 能够区分 AI 研究、模型训练、AI 应用工程、AI 平台工程的职责边界
- [x] 能够用「输入 → 模型 → 工具 → 评估 → 交付」框架描述一个 AI 工程系统
- [x] 能够判断自己当前该优先补概念、补代码能力，还是补系统设计能力

### 二、模型、数据与提示基础
- [x] 能够解释大模型如何把自然语言请求转化为可执行输出
- [x] 能够设计可复用的提示词结构，并识别提示词失效的常见原因
- [x] 能够判断一个任务是否需要 RAG、微调、工具调用，还是普通提示即可

### 三、AI 应用工程主线
- [x] 能够拆解一个 AI 应用的核心模块：上下文构造、模型调用、状态管理、工具执行、结果展示
- [x] 能够设计一个最小可用的 AI Agent，并说明其循环、记忆、工具和终止条件
- [x] 能够为 AI 应用设计错误处理、重试、限流、缓存和成本控制方案

### 四、评估、部署与迭代
- [x] 能够为 AI 功能设计离线评估集、在线监控指标和人工反馈流程
- [x] 能够解释 AI 系统常见风险：幻觉、越权工具调用、提示注入、数据泄露、不可复现输出
- [x] 能够制定一条从入门到项目落地的个人学习路线，并用项目验证每个阶段的掌握度

## 不在本课题范围内

- 不系统讲解深度学习数学推导，如反向传播、Transformer 论文细节、优化器推导。
- 不训练从零实现大模型，也不覆盖大规模 GPU 集群训练工程。
- 不以某一个商业平台为唯一主线；会讲通用工程能力，再映射到具体工具。
- 不承诺覆盖所有最新模型发布动态；重点放在可迁移的工程方法。
