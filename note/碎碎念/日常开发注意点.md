# 强制
1. ~~MyBatis 注册全局 configration 不要添加 typeHandler，会覆盖指定字段的 typeHandler~~    
2. mysql `select for update` 方式加分布式锁，使用唯一索引/主键索引
3. 使用 `stream toMap` 的时候强制需要处理 key 重复场景
4. 禁止使用 `record` 关键字，防止出现 Jackson 序列化兼容异常
5. 不得使用 hutool，fastjson
## 建议

1. `springBean` 以后使用**构造函数注入**，字段的初始化也放在构造函数中，方便单元测试
2. 不建议使用 lombok 的 `@UtilityClass` 注解，会让人产生困惑。
3. 函数返回值最好不要返回 `Optional`，避免有人返回 `null` 导致的额外判空 -> `if (Objects.nonNull(res) && res.present())`
4. 集合，判空等操作最好使用 Objects，CollectionUtils 这种工具类 （仅限于 apache 和 jdk 原生依赖中的工具类）
