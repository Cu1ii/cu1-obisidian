## 结论 1：贪心切分最小组数的正确性

### 问题定义

有一个正整数数组 $A = [a_1, a_2, ..., a_n]$ 和一个正整数 $X$。将数组 $A$ 切分成若干个**连续**的子数组（组），要求**每一组的元素和 ≤ X**，目标是最小化切分的组数。

**贪心策略**：从 $a_1$ 开始，每一组尽可能多地取元素（取到和不超过 $X$ 的最长前缀），得到 $K$ 组。

**待证**：$K$ 是所有合法切分中组数最小的。

---
### 符号定义

| 符号    | 含义                      |
| ----- | ----------------------- |
| $p_i$ | 贪心前 $i$ 组覆盖到的最后一个元素的下标  |
| $q_i$ | 最优解前 $i$ 组覆盖到的最后一个元素的下标 |
| $k$   | 贪心算法产生的组数               |
| $m$   | 最优解的组数（所有合法切分的最小组数）     |

---

### 引理：贪心始终领先

**引理陈述**：对任意 $i \ge 1$，贪心前 $i$ 组覆盖的元素数不少于最优解前 $i$ 组覆盖的元素数，即 $p_i \ge q_i$。

**归纳证明**：

**Base $i = 1$**：
贪心的第一组 $G_1$ 取的是满足和 ≤ X 的**最长**前缀。如果最优解的第一组 $O_1$ 结束得更早（$q_1 < p_1$），那么 $O_1$ 还可以继续添加后面的元素而仍然满足和 ≤ X —— 这与贪心取了最长前缀矛盾。因此 $p_1 \ge q_1$。

**Inductive Step**：
假设 $p_i \ge q_i$ 成立。考虑剩下的子数组：
- 贪心从 $A[p_i+1 .. n]$ 中取 $G_{i+1}$
- 最优解从 $A[q_i+1 .. n]$ 中取 $O_{i+1}$

由于 $p_i \ge q_i$，有 $p_i+1 \ge q_i+1$（贪心的剩余起点不早于最优解的剩余起点）。

分两种情况：

- **情况 1**：如果 $q_{i+1} \le p_i$，即最优解的第 $i+1$ 组完全落在贪心前 $i$ 组已覆盖的区域内，则显然 $p_{i+1} \ge p_i \ge q_{i+1}$，成立。

- **情况 2**：如果 $q_{i+1} > p_i$，那么 $O_{i+1}$ 覆盖了 $A[q_i+1 .. q_{i+1}]$，且 $sum(O_{i+1}) \le X$。

  由于 $p_i \ge q_i$，子数组 $A[p_i+1 .. q_{i+1}]$ 是 $O_{i+1}$ 的一个**后缀**。所有元素都是正数，所以后缀和 ≤ 整体和，即：
  $$sum(A[p_i+1 .. q_{i+1}]) \le sum(O_{i+1}) \le X$$

  贪心的 $G_{i+1}$ 取的是**最长**的满足和 ≤ X 的前缀。既然 $A[p_i+1 .. q_{i+1}]$ 的和已经 ≤ X，那么 $G_{i+1}$ 至少会延伸到 $q_{i+1}$（甚至更远）。因此 $p_{i+1} \ge q_{i+1}$。

由归纳法，**对所有 $i \ge 1$，有 $p_i \ge q_i$**。

---

### 结论：贪心组数达到最小值

**Step 1 — 证明 $k \le m$**：

最优解用 $m$ 组覆盖完整的数组，所以它的第 $m$ 组一定结束在最后一个元素 $n$，即 $q_m = n$。

由引理 $p_i \ge q_i$，取 $i = m$：
$$p_m \ge q_m = n$$

$p_m$ 是贪心前 $m$ 组覆盖到的最后一个元素的下标。$p_m \ge n$ 意味着贪心算法的**前 $m$ 组已经覆盖了所有 $n$ 个元素**。因此贪心实际需要的组数不可能超过 $m$：
$$\boxed{k \le m}$$

**Step 2 — 证明 $k \ge m$**：

$m$ 是所有合法连续切分的**最小组数**（最优解的定义）。贪心算法本身也是一个合法切分，因此它的组数不可能小于 $m$：
$$\boxed{k \ge m}$$

**Step 3 — 综合**：

由 $k \le m$ 且 $k \ge m$ 得：
$$\boxed{k = m}$$

**结论**：贪心算法切分出的组数 $K$ 等于最小值 $m$，即贪心策略达到最小组数。✅

---

### 证明主线速览

```
p_i ≥ q_i (引理：贪心始终领先)
  → p_m ≥ q_m = n
  → 贪心前 m 组已覆盖所有元素 → k ≤ m
  → 又因 m 是最小值 → k ≥ m
  → k = m
  → 贪心达到最小组数 ✓
```

---

### 关键前提

1. **正整数数组**：证明中用到了"后缀和 ≤ 整体和"的性质，这要求所有元素为正数。如果数组可以包含 0 或负数，结论不一定成立。

2. **和 ≤ X 是硬约束**：每一组的和不能超过 $X$。如果允许超过 $X$，则可以一组装下所有元素，组数恒为 1，问题无意义。
